Sinh viên: Nguyễn Trần Nhật Tiến | Mã SV: CDCNTT18B23 | Lớp: CDCNTT18B

## 1. Mô tả
Dùng module fs tạo tập tin thongtin.txt chứa họ tên và mã sinh viên, đọc và
hiển thị nội dung, ghi nối thêm tên lớp bằng appendFile(), sau đó đọc lại để
chứng minh nội dung đã được cập nhật.

## 2. Các lệnh thực hiện

Bước 1: Tạo file bai03.js

    cd B2/Bt03
    New-Item bai03.js -ItemType File

Bước 2: Viết code (writeFileSync, readFileSync, appendFile)

Bước 3: Chạy chương trình

    node bai03.js
